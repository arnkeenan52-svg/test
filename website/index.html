FAQ

Good questions.

Does it really build inside Roblox Studio?

Yes. Forge installs as a native dock widget. You type a request, hit Generate, and it creates the actual Script, LocalScript, ModuleScript, GUI, and terrain instances in the correct services — with full undo.

How is this different from a code chatbot?

Chatbots hand you a snippet to paste. Forge places working, server-authoritative systems directly into your game, builds the world around them, and then learns from your playtests to optimize. The runtime loop is something no other tool does.

Is the generated code safe to ship?

Forge enforces best practices by default: the server never trusts the client, remotes are validated, DataStores are pcall-wrapped with retries and BindToClose. It’s built to survive production traffic.

Can I cancel anytime?

Yes — monthly, cancel whenever. The Free plan stays free forever.
